Chapter 4 — Company Setup & Initial Configuration Flow
4.1 Purpose

This chapter defines the complete workflow that occurs immediately after a user successfully creates an account and logs into Co-op for the first time.

The Company Setup Wizard ensures that Co-op is personalized for the user's business before they begin managing orders, inventory, customers, or reports.

The setup process should be:

Simple
Guided
Intelligent
Fast
Skippable only where appropriate
Required before accessing the Dashboard

Once completed, Co-op creates the business profile, initializes the workspace, and prepares the application for daily use.

4.2 Objectives

The Company Setup Wizard must:

Create the user's business profile.
Configure regional settings.
Initialize business preferences.
Set up invoice branding.
Configure AI business context.
Create default application settings.
Prepare the local SQLite database.
Synchronize the company profile with Supabase.

The wizard consists of six sequential steps:

Step	Description
1	Welcome
2	Business Information
3	Branding

4.9 Step 5 — AI Initialization

The AI Assistant needs business context before providing useful recommendations.

Co-op creates an AI profile using:

The AI uses this information to:

Answer business questions

No confidential data is sent until the user explicitly requests AI assistance.

4.15 Error Handling

Possible setup errors include:

Error	Recovery
Invalid email	Correct the email address
Logo upload failed	Retry or skip
Database initialization failed	Retry setup
Cloud synchronization failed	Save locally and sync later
Import validation errors	Display invalid rows and continue after correction

The user should never lose entered information due to an error.

4.16 Offline Behavior

If internet connectivity is unavailable during setup:

Local company profile is created.
SQLite stores all configuration.
Cloud synchronization is queued.
AI initialization is deferred until internet access returns.

A notification informs the user:

"Your business has been set up successfully. Cloud synchronization will begin when an internet connection is available."

4.19 Developer Implementation Notes

Implementation guidelines:

Build the setup wizard as a multi-step React component with progress tracking.
Persist each completed step locally to prevent data loss if the application closes unexpectedly.
Validate all required fields before advancing.
Upload branding assets to Supabase Storage after local persistence.
Generate default settings immediately after successful completion.
Start background synchronization only after the local configuration is saved.
Allow users to revisit and edit all configuration values later through Settings → Company Profile.
4.20 Acceptance Criteria

The Company Setup & Initial Configuration Flow is complete when:

The setup wizard launches automatically for first-time users.
All required business information is collected and validated.
Company branding can be uploaded successfully.
Regional settings are applied throughout the application.
AI is initialized with the business profile.
Optional data import functions correctly.
Configuration is saved locally and synchronized with Supabase.
Offline setup is fully supported.
Users are taken directly to the Dashboard after successful completion.
Future expansion for multi-company support can be added without redesigning the flow.
4.21 Chapter Summary

This chapter defines how Co-op transitions from a newly registered account to a fully configured business workspace. The Company Setup Wizard creates the business profile, applies branding and regional settings, initializes AI, and prepares the local and cloud databases. By guiding users through a structured yet efficient setup process, Co-op ensures every workspace is ready for productive use from the very first session.
