Chapter 8 — Database Design & Data Models
8.1 Purpose

This chapter defines Co-op's complete data architecture, including the database schema, entity relationships, synchronization metadata, constraints, indexing strategy, audit logging, and migration approach.

The database is designed with the following principles:

Offline-first
High performance
Easy synchronization
Auditability
Scalability
Data integrity

8.24 Migrations

Migration naming convention:

001_initial_schema

002_add_products

003_add_ai_history

004_add_reports

005_add_sync_queue

Rules:

Never edit an existing migration.
Always create a new migration for schema changes.
Test migrations against both SQLite and PostgreSQL.
8.25 Data Validation

Validation occurs at:

Critical constraints should always be enforced by the database.

8.26 Data Retention

Business records are retained indefinitely unless explicitly deleted by the user.

Recommendations:

Keep AI history for 12 months by default (user configurable).
Keep audit logs indefinitely.
Preserve historical orders even if customers or products are archived.
8.27 Backup Strategy

Manual backups include:

SQLite database
User settings
Generated reports (optional)

Restore process:

Select backup file.
Validate version compatibility.
Restore database.
Rebuild indexes if necessary.
Confirm successful restore.
8.28 Security Considerations
Enable Row Level Security (RLS) in Supabase.
Use UUIDs for primary keys.
Encrypt sensitive local data.
Never store plaintext passwords.
Store API secrets only on the backend.
Validate all foreign key relationships.

Chapter Summary

This chapter defines Co-op's data foundation. The combination of SQLite for offline storage and Supabase PostgreSQL for cloud synchronization provides a resilient, scalable architecture that supports offline-first operation while maintaining data integrity and security.

The schema emphasizes auditability, synchronization, and future extensibility, ensuring Co-op can evolve from a single-user desktop ERP into a broader business operating system.
